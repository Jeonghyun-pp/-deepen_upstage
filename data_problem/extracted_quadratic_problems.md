#### 9번 문제 [cite: 62, 63]

7. $2 \int_{0}^{3} ax^{2} dx = 2 [\frac{a}{3} x^{3}]_{0}^{3} = 2 \times 9a = 18a$ 입니다. [cite: 590-591]

**21. 출제의도 : 함수의 극한의 성질을 이용하여 주어진 조건을 만족시키는 함수를 구할 수 있는가?**
정답풀이 :
1. $f(x) = (x - 1)(x - 2)$ 입니다.
2. (i) $a < 1$ 또는 $a > 2$일 때, $\lim_{x \to a} \frac{g(x) \times |f(x)|}{f(x)} = \lim_{x \to a} \frac{g(x) \times f(x)}{f(x)} = \lim_{x \to a} g(x) = g(a)$ 입니다.
3. (ii) $1 < a < 2$일 때, $\lim_{x \to a} \frac{g(x) \times |f(x)|}{f(x)} = \lim_{x \to a} \frac{g(x) \times (-f(x))}{f(x)} = -\lim_{x \to a} g(x) = -g(a)$ 입니다.
4. (iii) $a = 1$일 때, $\lim_{x \to 1-} \frac{g(x) \times |f(x)|}{f(x)} = \lim_{x \to 1-} \frac{g(x) \times f(x)}{f(x)} = \lim_{x \to 1-} g(x) = g(1)$ 이고, $\lim_{x \to 1+} \frac{g(x) \times |f(x)|}{f(x)} = \lim_{x \to 1+} \frac{g(x) \times (-f(x))}{f(x)} = -\lim_{x \to 1+} g(x) = -g(1)$ 입니다.

6. (iv) $a = 2$일 때, $\lim_{x \to 2-} \frac{g(x) \times |f(x)|}{f(x)} = \lim_{x \to 2-} \frac{g(x) \times (-f(x))}{f(x)} = -\lim_{x \to 2-} g(x) = -g(2)$ 이고, $\lim_{x \to 2+} \frac{g(x) \times |f(x)|}{f(x)} = \lim_{x \to 2+} \frac{g(x) \times f(x)}{f(x)} = \lim_{x \to 2+} g(x) = g(2)$ 입니다.

#### 28번 문제
[문제] 삼차함수 $ f(x) $ 와 실수 전체의 집합에서 미분가능한 함수 $ g(x) $ 가 모든 실수 $ x $ 에 대하여  
$ f(x) = g(x) - \tan g(x) $  
이고 다음 조건을 만족시킬 때, $ g^{\prime}(0) \times (g(0))^{2} $ 의 값은? [4점] [cite: 346, 348, 349, 353]

<div style="border: 1px solid currentColor; padding: 20px; margin: 10px 0; border-radius: 5px;">
  <div style="text-align: center; margin-bottom: 10px;"></div>

  (가) $ f(0) = 0 $, $ f^{\prime\prime}(\pi) = 0 $ [cite: 354]

</div>

① $ -12 $  ② $ -6 $  ③ $ -1 $  ④ $ 3 $  ⑤ $ 9 $

[해설]
* 출제의도: 여러 가지 미분법을 이용하여 미분계수와 함숫값을 구할 수 있는가?
* 풀이:
  1. $\sin g(\pi) = 0$에서 $g(\pi) = n\pi$인 정수 $n$이 존재합니다.
  2. $f^{\prime}(x) = g^{\prime}(x) - \sec^{2} g(x) \times g^{\prime}(x) = g^{\prime}(x)(1 - \sec^{2} g(x)) = -g^{\prime}(x) \tan^{2} g(x)$ 의 양변에 $x = \pi$를 대입하면 $f^{\prime}(\pi) = -g^{\prime}(\pi) \tan^{2} g(\pi) = 0$ 입니다.
  3. 조건 (가)에서 $f^{\prime\prime}(\pi) = 0$이므로 $f(x) = a(x - \pi)^{3} + b$ ($a, b$는 상수, $a \ne 0$)이고 $f(0) = -a\pi^{3} + b = 0$이므로 $b = a\pi^{3}$, 즉 $f(x) = a(x - \pi)^{3} + a\pi^{3}$ 입니다.
  4. 그러므로 $f(\pi) = a\pi^{3}$이고 $f(\pi) = g(\pi) - \tan g(\pi) = n\pi$이므로 $a\pi^{3} = n\pi$에서 $a = \frac{n}{\pi^{2}}$ 입니다.
  5. 이때 모든 실수 $x$에 대하여 $\tan g(x)$가 정의되기 위해서는 모든 실수 $x$에 대하여 $g(x) \ne k\pi + \frac{\pi}{2}$ ($k$는 정수)이어야 합니다. $\cdots\cdots$ ㉠
  6. 또 $f^{\prime}(x) = 3a(x - \pi)^{2}$이므로 $3a(x - \pi)^{2} = -g^{\prime}(x) \tan^{2} g(x)$ $\cdots\cdots$ ㉡
  7. (i) $a > 0$인 경우, $x$가 $\pi$가 아닐 때 $g^{\prime}(x) < 0$이므로 $g(x)$는 감소하고 $n > 0$입니다. $x > \pi$일 때 $g(\pi) = n\pi$에서 $g(x)$는 $\frac{3}{2}\pi$로 감소하므로 $n\pi > \frac{3}{2}\pi$, 즉 $n > \frac{3}{2}$ 입니다.
  8. $x > \pi$일 때 $\frac{3}{2}\pi < g(x) < n\pi$이므로 ㉠에서 $n\pi \le \frac{5}{2}\pi$, $n \le \frac{5}{2}$ 입니다. 즉, $\frac{3}{2} < n \le \frac{5}{2}$이므로 $n = 2$ 입니다.
  9. (ii) $a < 0$인 경우, $x$가 $\pi$가 아닐 때 $g^{\prime}(x) > 0$이므로 $g(x)$는 증가하고 $n < 0$입니다. $g(\pi) = n\pi$에서 $g(x)$는 $\frac{3}{2}\pi$로 증가하는데 ㉠에 의하여 모순입니다.
  10. (i), (ii)에서 $n = 2$이므로 $a = \frac{2}{\pi^{2}}$ 입니다.
  11. $f(0) = g(0) - \tan g(0) = 0$에서 $\tan g(0) = g(0)$ 이고, $f^{\prime}(0) = -g^{\prime}(0) \tan^{2} g(0) = -g^{\prime}(0)(g(0))^{2}$ 입니다.
  12. 따라서 $g^{\prime}(0) \times (g(0))^{2} = -f^{\prime}(0) = -3a\pi^{2} = -3 \times \frac{2}{\pi^{2}} \times \pi^{2} = -6$ 입니다.
* 정답: ②
